# 壽險佣金率比較與高亮分析技能

當使用者提出需要比較各壽險公司商品佣金率、篩選特定繳費年期，或是尋找最高佣金率商品時，使用此技能。

## 1. 核心公式與規則

1. **首年實際佣金率 (FYC%) 計算**：
   $$\text{初年度服務報酬 (FYC\%)} = \text{初年度業績換算率} \times 40\%$$
   
2. **高亮規則**：
   * **公司內部最高項目**：每一家壽險公司旗下符合篩選條件的商品中，首年實際佣金率 (FYC%) 最高者，在表格與簡報中必須使用 **紅色加粗**（HTML 格式為 `<span style='color:red; font-weight:bold;'>`）表示該商品的名稱、代號與首年佣金率。
   * **跨公司全場最高項目**：全場最高項目除了套用紅字粗體外，應在摘要或首頁顯著提及。

3. **遠雄人壽特定商品排除**：
   * 在處理遠雄人壽的 3 年期商品時，必須主動**排除**豁免類商品：`HB4`、`HZ1`、`HA4`、`MC1`，僅保留利變增額或還本儲蓄型主力商品（如 `WM1`、`SX1`）。

---

## 2. PDF 資料解析邏輯

1. **商品名稱關聯**：
   * 保險公司佣金 PDF 中，多個年期常共用同一個商品名稱，導致文字提取時某些資料列的商品名稱欄位為空。
   * **解決方案**：
     * **第一階段**：掃描頁面所有含有日期的資料列。若同列前方有中文商品名稱，則建立 `代號 -> 名稱` 映射表。若無，則檢查該資料列前後 2 行內是否存在「僅有中文商品名稱」的獨立行，若有則進行關聯。
     * **第二階段**：使用建立好的映射表，動態補全所有資料列的商品名稱。

2. **黏合欄位分割**：
   * 在提取遠雄人壽等 PDF 時，數值可能因字距過窄黏合（例如 `1.500.800.80`）。
   * **解決方案**：
     * 使用正則表達式 `re.findall(r'\d+\.\d{2}', field)` 匹配所有帶兩位小數的數值，將其展開為獨立的數值陣列（如 `['1.50', '0.80', '0.80']`），再對齊各年度的續期報酬率欄位。

---

## 3. 自動化腳本庫

本技能附帶三個 Python 自動化腳本，存放於 `scripts/` 目錄中：

1. `generate_three_year_report.py`：掃描 PDF、篩選 3 年期、排除遠雄特定商品、計算首年 FYC%，並輸出高亮後的 Markdown 報表。
2. `build_html_slides.py`：將篩選高亮後的資料動態組裝成 Reveal.js HTML 簡報，自動適應暗色科技風格。
3. `deploy_slides.py`：初始化 Git 儲存庫、將簡報推送到 GitHub，並自動調用 GitHub API 啟用 GitHub Pages 線上展示。
