# 版本紀錄 (Changelog)

本專案遵循 [Semantic Versioning](https://semver.org/lang/zh-TW/) 版本規範。

---

## [v1.0.0] - 2026-09-30

### 🎉 初始發布 (Initial Release)

* **前台線上報名系統 (Web App)**：
  * 基於 Google Apps Script (GAS) 構建，透過 `appsscript.json` 配置 `"access": "ANYONE_ANONYMOUS"`，保證一般大眾免登入 Google 帳號、免任何授權即可秒填報名。
  * 響應式手機優先（Mobile-First）大字版排版，自適應活動主題配色（科技藍、商務金等）。
  * 友善低阻力欄位：姓名為唯一必填，聯絡電話與 Email 預設為選填。
* **短網址與高解析 QR Code 自動化**：
  * 整合 Reurl.cc 官方 API 自動縮短長網址。
  * 自動生成 600px 高畫質 `qrcode.png` 與 `checkin_qrcode.png`，可直接用於社群宣傳或列印實體立牌。
* **雙重 Email 自動化發信排程**：
  * 即時報名確認信：填寫 Email 之民眾送出當下自動發送，內含活動時間、地點、費用與 Google 地圖路線導航按鈕。
  * 行前提醒信：程式內建 `ensureReminderTrigger()`，自動於**活動前一天傍晚 18:00 定時發信**，不需手動建立觸發器。
* **現場掃碼快速簽到系統**：
  * 內建專屬路由 `?page=checkin`，與報名系統同享憑證與後台試算表。
  * 極簡介面：只有「你的大名」輸入框與 `<送出簽到>` 按鈕，3 秒快速報到。
  * 送出後呈現「報到成功卡片」，並附有「➕ 替同行友人簽到」按鈕。
* **後台試算表雙重連動機制**：
  * 主表 (`gid=0`) 智慧比對：自動比對第 2 欄姓名，已預先報名者在第 10 欄標記 `已簽到 (時間)` 並上柔和淺綠底色（`#f0fdf4`）；現場直接來賓自動新增列並上淺藍底色（`#eff6ff`）。
  * 獨立「現場簽到紀錄」分頁：依實際到場先後順序以流水序號排序列出，接待統計零時差。
  * 後台試算表專屬短網址：主辦團隊在手機 LINE 就能一鍵開啟查閱名冊。
