# 🚀 開工接續助手 (`startup` skill)

> **版本**：`v1.0.0`  
> **適用類型**：Antigravity / AI Coding Assistant  
> **核心職責**：自動進行「開工脈絡接續」，協助使用者與 Agent 在新 Session 迅速接頭上次的工作進度。

---

## 📖 技能簡介

`startup` 是一個具備**三層級自動偵測（L1 本地 / L2 GitHub / L3 Obsidian）**的開工接續技能。當開啟新的對話 Session 時，AI Agent 會依照專案建立的層級，讀取專案藍圖、跨電腦交接檔與 Git 狀態，給予使用者精簡且結構化的現狀報告與下一步建議，避免每次都要重頭解釋進度。

---

## 🎯 觸發關鍵字

當使用者輸入以下任何內容時，將自動觸發本技能：
- `開工`
- `開始工作`
- `我來了`
- `上次做到哪`
- `我們繼續`
- `接下來呢`
- `接續工作`
- `來吧`

---

## 🏗️ 三層級偵測架構

| 層級 | 偵測條件 | 執行的開工動作 |
| :--- | :--- | :--- |
| **L1 本地** | 專案存在 `AGENTS.md` / `handoff.md` | **讀取**專案藍圖與交接檔，檢查最後更新者與電腦名稱 |
| **L2 GitHub** | 專案存在 `.git` 目錄 | 執行 `git status` 與遠端 fetch 檢查，提示是否有未 commit 修改或遠端更新 |
| **L3 Obsidian** | `AGENTS.md` 登記 Obsidian 筆記路徑 | 列出詳細筆記路徑（**預設不主動讀取**，保護 Context 空間） |

---

## 📋 執行 SOP 流程

1. **讀取 L1 藍圖與交接檔**：
   - 摘要 `AGENTS.md`（專案目標、路線圖）
   - 讀取 `handoff.md`（上次做到哪、目前狀態、下一步、注意事項）
   - 檢查更新者電腦名稱：若與當前電腦不同，提醒 `⚠️ 上次在另一台電腦收工` 並確認同步。
2. **L2 Git 狀態檢查**：
   - 檢查本地工作區是否乾淨
   - 檢查遠端是否有落後的 commit（不自動 `git pull`，僅提醒）
   - 交叉比對 `handoff.md` 記載與實際遠端 commit 是否吻合。
3. **L3 Obsidian 筆記提示**：
   - 在報告中附上筆記路徑，僅在「下一步指向筆記」或「使用者要求」時才深入讀取。
4. **輸出結構化報告**並等待使用者選擇方向。

```text
   1. 補充 Repo README 檔案說明
   2. 測試跨電腦同步防呆機制

要從哪個方向開始？
```
